This proposal is one candidate implementation for the request: We have a plan as follow, lets show how to install a CLI in readme and finish `ugit serve -m machine-x [-p local-port (default: same as serverPort in config)]`. ugit is git service running on your remote machine. - git remote set to ssh URL of ugit server - use `ugit` command to create a PR. - the repository is synced using git - when receving a PR via http, ugit starts a process to run CI and then merge the PR if CI is successful. ugit will run each `.ugit/workflows/[workflow]/` (A NPM package) to validate. queue CI job at the commit in the remote server. can run one CI job on each remote repository at the same time. at most 4 CI jobs can be run at the same time in the remote server. remote server will checkout the branch and run CI job, and then push the result to the remote repository. the result is stored in `.data/ci-results/[repo-name]/[branch-name].json`. - all of the network communication is done via ssh or http over ssh Initialize a CLI using clipanion, located in `/packages/ugit-cli/src/main.ts`: - the config is stored in `~/.local/share/ugit/config.json` and contains: ```jsonc { "machines": { "local": { // specially treated as localhost rather than a remote machine, so that the remote url is `/path/to/ugit/server/.data/repos` instead of `ssh://kamiya-machine-x/absolute/path/to/repo.git` "ssh-machine": "localhost", "path": "/path/to/ugit/server", "serverPort": 3001 } "machine-x": { "ssh-machine": "kamiya-machine-x", "path": "/path/to/ugit/server", "serverPort": 3001 } } } ``` - setup a local repository in the remote ugit server: ```bash ugit create -m machine-x [directory (default: current directory)] ``` A remote repository is initialized in `.data/repos/[repo-name]`, and the origin of the local repository is set to the ssh URL of the remote repository. the local repository must have a upstream remote, which will be copied to the remote repository as `upstream` remote (assumed being a github URL). ugit push to the remote repository will be synced to the remote repository. This also writes a git local config to record which machine the repository is connected to, so that we can use `ugit` command in the repository without specifying the machine name. - forward a remote server port to local: ```bash ugit serve -m machine-x [-p local-port (default: same as serverPort in config)] ``` - publish PR using the CLI: ```ts export type GitPlatformPublishedBranch = { repositoryPath: string; branchName: string; commitHash: string; remoteName?: string; pushedAt?: string; }; ``` - synchronize PR using the CLI: ```ts export type SynchronizeGitPlatformPullRequestArgs = { repositoryPath: string; branchName: string; baseBranch: string; title: string; body: string; draft?: boolean; remoteName?: string; }; ```.
